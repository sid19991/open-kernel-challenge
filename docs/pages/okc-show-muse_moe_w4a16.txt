◆ muse_moe_w4a16

Routed experts. Top-8 of 256 experts at width 4096: SwiGLU, NVFP4 weights, and a
norm on each expert’s output before it is weighted and summed.

  SGLang      13.45 ms  per decode step
  GPU         H200  one, no network
  Limits      10 runs and 20 checks a day

Computation
  # per token: its top 8 of 256 experts; only local ones here
  for t, (e, g) in routes if e is local:
      h = x[t] @ dequant(w13[e]).T
      gate, up = split(h)
      y = (silu(gate) * up) @ dequant(w2[e]).T
      out[t] += g * rmsnorm(y * (1 + post_norm_w))

Inputs
  kernel_fn(data: Inputs, state) returns bfloat16 [M, H]. state is what
  prepare(weights) returned.

  class Inputs(TypedDict):
      hidden_states: torch.Tensor  # bfloat16 [M, H]
      topk_ids: torch.Tensor       # int32 [M, 8], global expert ids (0-255)
      topk_weights: torch.Tensor   # float32 [M, 8]
      config: Config

  class Weights(TypedDict):
      # uint8 [256, 2I, H/2], gate rows [0, I) then up rows [I, 2I), packed E2M1
      w13: torch.Tensor
      w13_sf: torch.Tensor       # float8_e4m3fn [256, 2I, H/16]
      w13_gs: torch.Tensor       # float32 [256]
      w2: torch.Tensor           # uint8 [256, H, I/2]
      w2_sf: torch.Tensor        # float8_e4m3fn [256, H, I/16]
      w2_gs: torch.Tensor        # float32 [256]
      # bfloat16 [H], the post-expert RMSNorm's weight (applied as 1 + w)
      post_norm_w: torch.Tensor

  class Config(TypedDict):
      bs: int           # tokens, M
      d_hidden: int     # H = 4096, the width the MoE block runs its experts at
      d_expert: int     # I = 4096
      n_experts: int    # 256 experts in the model
      # this GPU computes experts [local_start, local_start + local_count)
      local_start: int
      local_count: int  # 32: one GPU under 8-way expert parallelism
      top_k: int        # 8
      sharding: str     # "ep8"

Scored shapes
  load        bs    weight
  ────────────────────────
  decode 1    1     60
  decode 16   16    60
  decode 32   32    60
  verify 1    8     60
  verify 16   128   60
  verify 32   256   60

  bs (M in the shapes) is the tokens per step: 1, 16 and 32 for decode, and 8,
  128 and 256 for 8-token verify blocks. The weights arrive once, in prepare(),
  untimed.

  This GPU holds 32 of the 256 experts, as under 8-way expert parallelism. Every
  token arrives, and only its routes to local experts are computed.

  Routings follow real routers’ skewed expert popularity. A step waits for the
  busiest GPU, so each routing makes this GPU the busiest.

  Decode loads are SGLang serving with speculative decoding off; verify loads
  are its default recipe, which checks each request's 8-token draft in one step.
